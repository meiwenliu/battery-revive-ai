# 《焕芯·电愈智策》制造端碳减排核算方法学与科学边界

## 1. 核心数学模型
1. 单体电池可恢复电能：$E_{rec} = Q_{rec} \times V_{mean,dis}$
2. 电池包等效恢复电量：$E_{pack,rec} = E_{pack} \times \frac{\sum Q_{rec}}{\sum Q_{before}}$
3. 制造端规避碳减排潜力：$GHG_{avoided} = E_{pack,rec} \times EF_{mfg}$ ($EF_{mfg} = 105\text{ kgCO}_2\text{e/kWh}$)
4. 调理电网电耗抵扣：$GHG_{process} = E_{recond} \times EF_{grid}$ ($EF_{grid} = 0.5810\text{ kgCO}_2\text{e/kWh}$)
5. 净规避碳减排量：$GHG_{net} = GHG_{avoided} - GHG_{process}$
6. 常压 CO₂ 气体体积：$V_{CO2} = GHG_{net} / 1.80\text{ kg/m}^3$

## 2. 科学边界声明
- 核算数据为制造端等效规避潜力，实际净减排取决于地方电网清洁度；
- 系统定位于快速健康筛选、价值评估与分选决策支持工具，不替代出厂绝缘及耐压等物理安全强检项。
