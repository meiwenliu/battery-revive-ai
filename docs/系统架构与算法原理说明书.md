# 《焕芯·电愈智策》系统架构与算法原理说明书

## 1. 系统总体架构

系统采用高内聚、低耦合的分层架构体系：
1. **数据采集与直连层**：支持 16 通道动力电池测试柜实时采样流输入，支持 CSV/Excel 批量上传与标准样例库一键加载。
2. **特征工程与提取层**：
   - 脉冲激励响应时序中提取 8 项物理特征 ($U_0, R_{dc,chg}, R_{dc,dis}, \Delta R_{dc}, \eta, asym, \Delta V_{relax}, SOC$)；
   - 单次充放电循环中提取 5 项当前状态特征 ($Q_{dis}, CE, EE, V_{mean,dis}, V_{hyst}$)。
3. **算法模型推理层**：
   - M1: 统一梯度提升回归树 (XGBoost) 浅树正则化诊断模型；
   - M2: 弹性网络回归 (ElasticNet) + 90% 保角预测区间模型；
   - Echelon: 四级智能分选矩阵与五维度机理雷达评级。
4. **宏观量化与决策层**：
   - M3: 制造端碳排放规避量 (105 kgCO₂e/kWh) 与电网电耗抵扣核算，等效常压 CO₂ 气体体积与生态碳汇折算；
   - Report: 一键生成学术与工程标准评估报告。
