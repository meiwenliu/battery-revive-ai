## 2. 核心特征字段定义与物理机理 (数据字典)

### 2.1 SOH 快速诊断特征 (PHYSICS_CORE 8项体系)
1. **电芯编号 (`cell_id` / `电芯编号`)**: 电池唯一物理识别码。
2. **测试荷电状态 (`SOC` / `测试荷电状态_SOC_pct`)**: 施加脉冲激励时电池所处的荷电状态百分比（如 20%, 50%, 80%, 95%）。
3. **稳态开路电压 (`U0_V` / `稳态开路电压_U0_V`, 单位: V)**: 零电流静置段最后 30s 电压中位数，直接映射活性锂损失导致的正负极平台偏移。
4. **放电直流电阻 (`Rdc_dis_ohm` / `放电直流电阻_Rdc_dis_ohm`, 单位: Ω)**: 10s 放电直流内阻，表征脱锂与固相传导阻抗。
5. **充电直流电阻 (`Rdc_chg_ohm` / `充电直流电阻_Rdc_chg_ohm`, 单位: Ω)**: 10s 充电直流内阻，表征嵌锂与界面反应阻抗。
6. **倍率依赖电阻差 (`dRdc_ohm` / `倍率敏感内阻差_dRdc_ohm`, 单位: Ω)**: 2C 与 1C 脉冲电阻之差，表征高倍率下固相扩散受限程度。
7. **持续极化电压 (`eta_V` / `持续极化电压_eta_V`, 单位: V)**: 60s 持续大电流放电极化增量 V(60s) - V(1s)。
8. **充放电不对称度 (`asym` / `充放电不对称度`, 无量纲)**: (R_dis - R_chg) / (R_dis + R_chg)，表征电极结构衰退引起的不对称势垒。
9. **撤载松弛电压 (`relax_V` / `撤载松弛电压_relax_V`, 单位: V)**: 撤电后 600s 电压弛豫恢复幅度 |V(600s) - V_off|。

### 2.2 容量可恢复性预测特征 (5项当前状态特征)
1. **当前放电容量 (`Q_dis_Ah` / `当前放电容量_Q_dis_Ah`, 单位: Ah)**: 调理前当前实测可用容量，反映电池剩余活性锂底数。
2. **库仑效率 (`CE` / `库仑效率_CE`, 无量纲)**: 当前循环放电容量与充电容量比值 Q_dis / Q_chg，表征副反应损失程度。
3. **能量效率 (`EE` / `能量效率_EE`, 无量纲)**: 当前循环放电能量与充电能量比值 E_dis / E_chg，表征欧姆与极化综合热耗。
4. **平均放电电压 (`V_mean_dis_V` / `平均放电电压_V_mean_dis_V`, 单位: V)**: E_dis / Q_dis，表征有效放电平台高低。
5. **平均电压滞后 (`V_hyst_V` / `平均电压滞后_V_hysteresis_V`, 单位: V)**: 平均充电电压与平均放电电压之差 V_mean_chg - V_mean_dis。
6. **真实可恢复容量 (`true_QREC` / `真实可恢复容量_Ah`, 单位: Ah)**: 恒压调理后实测净容量回升增量 Q_after - Q_before。

## 3. 梯次利用与低碳量化指标
- **SOH (健康状态, %)**: 当前可用容量占初始额定容量百分比。
- **RPI (恢复潜力指数, %)**: Q_rec / (Q_nominal - Q_dis) × 100%。
- **梯次分选评级**: A 级 (储能系统直接梯次), B 级 (深度调理恢复+低速车/备电), C 级 (农机/路灯降级利用), D 级 (材料回收提锂)。
- **制造端规避碳排放潜力 (GHG_avoided, kgCO₂e)**: 电池包等效恢复电量 × 105 kgCO₂e/kWh。
- **净碳减排量 (GHG_net, kgCO₂e)**: 规避制造排放扣除调理电网电耗排放。
- **常压 CO₂ 气体体积 (V_CO2, m³)**: GHG_net / 1.8 kg/m³。
