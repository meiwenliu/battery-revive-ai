# 焕芯·电愈智策——多体系电池智能快速诊断与低碳循环决策系统

## 一、系统简介

“焕芯·电愈智策”是面向多体系电池（涵盖磷酸铁锂 LFP、三元高镍 NCM/NCA、钠离子 Na-ion、硅碳负极等多材料体系，以及工商业储能、电网调峰储能、通信基站备电与长效循环全场景）构建的标准化智能快速诊断、容量可恢复性预估与制造端碳减排规避量量化决策平台。

系统针对传统电池分选耗时长（数小时标定）与残值评估单一（一刀切淘汰）两大行业痛点，构建了涵盖：
1. **实时硬件直连接口与动态采集**：支持 16 通道实时连接、高帧率动态示波器监测；
2. **SOH 快速健康诊断 (M1 模块)**：提取 8 项电化学物理特征，统一 XGBoost 模型实现分钟级快速诊断（LOBO MAE = 2.85%）；
3. **单次状态特征可恢复容量精准预估 (M2 模块)**：提取 5 项当前状态特征（无需全生命周期历史退化轨迹），基于弹性网络与 90% 保角预测区间精准预估净恢复容量（MAE = 0.0290 Ah, R² = 0.7502）；
4. **全场景四级智能分选决策**：自动判定 A 级（高价值储能直接循环再利用）、B 级（调理再生+储能/高敏备电应用）、C 级（轻型降额循环利用）、D 级（材料拆解定向提锂再生）；
5. **微观状态到宏观制造端碳减排规避量量化 (M3 模块)**：打通“单体恢复电能 → 电池包等效规避制造排放（105 kgCO₂e/kWh） → 调理电耗抵扣 → 净碳减排量（420.36 kgCO₂e / 60.48kWh pack） → 常压 CO₂ 气体体积（233.68 m³）与生态等效”完整量化链路。

## 三、快速启动方式

### 方式 1：双击一键启动（推荐）
直接双击运行 `scripts\启动系统.bat`，系统将自动启动 FastAPI 后端服务，并在默认浏览器中自动打开 `http://127.0.0.1:8000`。

### 方式 2：纯前端离线直接体验
直接双击打开 `frontend\index.html`，系统内置了**纯客户端高性能 JS 计算引擎**，即使在无 Python 环境下也能完成全部计算、示波器动态渲染与图表交互！
